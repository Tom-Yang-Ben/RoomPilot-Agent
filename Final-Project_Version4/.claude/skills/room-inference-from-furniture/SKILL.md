# 家具判別房間（Room Inference from Furniture）

本技能提供住宅平面圖的空間判定規則。核心原則：**先過濾、再投票、有矛盾就攔截、信心不足就說「未定」——絕不硬猜。**

判定流程固定為五步，順序不可調換：

1. 幾何過濾（第 4 節）——先剔除不可能的偵測結果
2. 上下文分流（第 3 節 R1–R3）——解決外觀相同的物件
3. 矛盾攔截(第 3 節 R4–R6)——抓出誤判
4. 權重投票（第 1、2 節）——計算空間名稱
5. 信心判定（第 5 節）——低於門檻輸出「未定」

## 第 3 節：上下文規則（R1–R6）

### R1｜水槽分流
sink 本身權重為 0，必看同空間鄰居：
- 同空間有 stove 或 range_hood → 判為廚房水槽，以 0.60 投給 kitchen
- 同空間有 toilet、bathtub 或 shower → 判為洗手台，以 0.60 投給 toilet/bathroom
- 兩者皆無 → 標記「未定」，不投票

### R2｜方框類分流
wardrobe / storage / shower 在圖上都可能是素面方框：
- 同空間有 toilet 或 bathtub → 判為 shower
- 同空間有 bed → 判為 wardrobe
- 皆無 → 判為 storage（不投票）

### R3｜桌類分流
- 桌子四周有 4 張以上椅子環繞 → dining_set
- 桌子貼牆、無環繞椅 → desk
- 桌子位於 sofa 正前方 1 公尺內 → coffee_table

### R4｜矛盾攔截（誤判警報）
以下組合同空間出現屬於異常，將**權重較低**的一方降級為「待確認」，不得投票：
- stove 與 toilet
- bed 與 bathtub
- stove 與 bed
- 同空間出現 2 個以上 bathtub → 只保留信心最高且通過第 4 節尺寸過濾者，其餘降級（多半是被誤判的馬桶或淋浴間）

### R5｜牆上物件排除（門→浴缸誤判的剋星）
任何偵測框，若中心點落在牆體多邊形內、或距牆中心線小於牆厚一半：
- **一律不得判為任何家具類別**，改判為門/窗候選或直接剔除
- 門和窗是牆上的開口，不是家具；家具中心點必然落在房間內部
- 此規則優先於一切信心值——即使模型 95% 確信是浴缸，位置在牆上就不是浴缸

### R6｜濕區反饋
- 被判 bathtub/shower 者，所在空間若同時有 bed 或 stove → 極可能是門或衣櫃的誤判，降級待確認
- 所在空間若有 toilet 或已分流的洗手台 → bathtub/shower 信心值加 0.10（上限 1.0）

## 第 4 節：尺寸與幾何過濾（需要比例尺）

若已知圖面比例尺，先過濾再投票。不符者降級「待確認」並保留模型第二高信心類別作為建議答案，**不要直接刪除**。

| 物件 | 面積範圍 | 短邊下限 | 長寬比範圍 | 備註 |
|---|---|---|---|---|
| toilet | 0.2–0.5 m² | 35 cm | 1:1.3–1:2.0 | |
| bathtub | 0.8–2.0 m² | 60 cm | 1:1.2–1:2.6 | 面積為主判準；長寬比放寬以容納日式泡澡缸 |
| door | 0.5–1.0 m² | — | 約 1:1（含開啟弧） | 包圍框近正方形 |
| bed | 1.8–4.5 m² | 90 cm | 1:1.4–1:2.2 | |
| sofa | 1.2–4.0 m² | 70 cm | — | |
| dining_set | 2.0–8.0 m²（含椅） | — | — | |
| refrigerator | 0.3–0.8 m² | 55 cm | 近 1:1 | |

三個關鍵判別（針對已知的高頻誤判）：
- **馬桶 vs 浴缸**：面積差約 4 倍（0.3 m² vs 1.1–1.5 m²），即使比例尺有 ±30% 誤差也不會重疊。被判浴缸但面積 < 0.8 m² → 改判 toilet 候選。
- **門 vs 浴缸**：門的包圍框近正方形且中心在牆上（R5）；浴缸長寬比 ≥ 1:1.2 且中心在房間內。
- **浴缸 vs 窗**：窗在牆上（R5 排除）；浴缸短邊 ≥ 60 cm，窗的深度即牆厚（通常 < 30 cm）。

無比例尺時跳過本節，但須在輸出中註明「未經尺寸驗證，信心下修 0.10」。

## 第 5 節：投票與輸出

1. 每個房間：把房內所有通過過濾與分流的物件，依其指向空間累加權重。
2. 取最高分空間；先檢查複合空間條件（第 2 節）。
3. 最高分 ≥ 0.90 → 直接輸出。
4. 0.60 ≤ 最高分 < 0.90 → 輸出但標註「建議人工複核」。
5. 最高分 < 0.60 → 輸出「未定」，列出偵測到的物件清單。**未定是合格答案，硬猜不是。**
6. 觸發 R4/R5/R6 的物件，必須在輸出中明列：物件、原判類別、觸發規則、建議處置。

### 輸出格式範例

```
房間 #2：衛浴 combined_bath（總分 2.53，高信心）
  依據：toilet(0.98) + shower(0.90) + sink→洗手台(0.60，R1分流)
房間 #3：未定（最高分 0.30）
  偵測到：side_table(0.30)。物件不足以定案，建議人工判定。
攔截清單：
  物件 #17 原判 bathtub(信心0.87) → 觸發 R5（中心點在牆上）→ 改判 door 候選
```

## 第 6 節：用於訓練資料準備時的附加守則

當本技能被用來協助標註、審查訓練資料或生成合成資料時：

1. **易混對必須成對出現**：訓練批次中 door 與 bathtub、toilet 與 bathtub、wardrobe 與 shower 應刻意混排（硬負樣本），迫使模型學差異。
2. **負樣本佔比 10–20%**：無家具的圖（空房、純牆線、文字密集區）必須進訓練集，標註為空。
3. **驗證集只能用真實圖**：合成圖不得混入驗證集，否則準確率虛高。
4. **標註審查順序**：先跑 R5（牆上排除）→ 再跑第 4 節尺寸過濾 → 剩餘的才需人眼看。可省 60% 以上人工。
5. **權重校準**：本表所有權重為起始值。累積混淆統計後，依實際誤判率回頭修正，特別是 wardrobe(0.55) 與 desk(0.25)。

---

## 禁止事項

- 不得在最高分 < 0.60 時輸出具體房名。
- 不得讓 sink 在 R1 分流前參與投票。
- 不得因模型信心值高就跳過 R5 牆上排除。
- 不得直接刪除被過濾的偵測結果——一律降級「待確認」並保留原判資訊。
- 不得對非住宅圖面（商場、辦公室、廠房）套用本表尺寸範圍；偵測到 urinal 數量 ≥ 2 或空間面積異常大時，提示使用者本技能以住宅為準。
