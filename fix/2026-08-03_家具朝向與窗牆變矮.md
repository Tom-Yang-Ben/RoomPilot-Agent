## 問題 1：家具朝向不對（沙發與電視櫃呈 L 型、躺椅面壁）

### 歸屬說明

朝向的「紀律」本來就在 `backend/agent/place.py` 的 `placement_hints()`
（主件先行、副件成組），成組候選表也早已寫好（`scene_service.py`
`_agent_prepend_candidates`：電視櫃放沙發正對面牆、茶几放沙發正前、
床頭櫃貼床頭、椅子面桌）。**agent 端不缺任何東西**——問題出在 server
端從未在第一次擺位時消費 agent 的 hints，修復因此落在 `backend/server/`，
依約定記錄於本檔。

### 根因（兩個互相疊加）

1. `build_scene_payload` 的**初次** `generate_layout_by_room` 呼叫不帶
   `hints`（只有放不下時的修復迴圈帶）。而 `generate_layout` 內
   `neighbors` 的登記被 `if hints and not failed_reason:` 把關——沒有
   hints 就永遠是空 dict，`_agent_prepend_candidates` 對每件家具都回 []。
   **成組候選整條路在正式路徑上是死的**：電視櫃拿不到「沙發對面牆」
   候選，落入靠牆掃描的「長邊優先」任意牆位。grwsgs 客廳實測：沙發
   西牆面東（rot 90），電視櫃被掃描放到南牆面北（rot 0），兩者呈 L 型
   ——`feedback.png` 的主訴。
2. `orient_layout_toward_targets` 的轉向名單只有 office-chair /
   dining-chair / armchair。**lounge-chair 不在名單**，又不在
   `_placement_candidates` 的類型表（走泛用 `(center, center, 0)`），
   rot 永遠 = 0（面 +z），在客廳常變成面壁或背對沙發組。

### 修復

- `build_scene_payload` 初次擺位補上 `hints=placement_hints(selected_items)`
  （`placement_hints` 是 agent 的既有函式；一行接線）。修復迴圈原本就帶，
  行為一致。
- `orient_layout_toward_targets` 的 `target_types` 加入
  `"lounge-chair": ("coffee-table", "sofa", "sofa-bed")`（與 armchair 同規則，
  貼齊 90°、轉後足跡不變）。
- `generate_layout` 的 `if hints` 把關**維持不變**：
  `test_engine_no_hint_matches_legacy_behavior` 契約（無 hint 呼叫 = 舊行為
  位元相同）仍成立。

## 問題 2：有窗戶的牆比左右的牆稍矮

### 根因

grwsgs 的 5 扇窗**全部位於牆縫**（第 4 步確認的牆段在窗兩側斷開，
`openingWallInterval` 對 19 段牆全數無 host）。外殼幾何中：

- 牆段頂蓋（top-cap）到 `牆高 + 2.5cm`（272.5）；
- 縫內窗的窗頂補實只到 `牆高`（270）——**開口跨距的頂線矮了 2.5cm**，
  斜視角下清楚可見（`feedback.png`）。此縫隙在重構前的
  `buildStandaloneOpeningAssemblies` 時代即存在（標準段同樣只到牆高），
  非重構引入；門縫上方同病。

另發現一個重構回歸：`step4_skip_wall_cut` 在純函式層被當成「整組略過」，
但 grwsgs 的 5 扇門全帶此旗標 → **門楣全部消失**（舊
`buildConfirmedDoorLeaves` 對每扇有牆縫線段的門都補 header，旗標從不參與）。

### 修復（`backend/server/static/scene_shell_geometry.js` 純函式層）

- 未被任何牆段 host 的窗/門，在自身線段上補一個 top-cap
  （`牆高..牆高+topCapHeightCm`、厚 = 牆厚），頂線跨過門窗連續；
  hosted 開口沿用牆段整段頂蓋、不重複發蓋。
- `step4_skip_wall_cut` 語意修正為「不得再切牆」：hosted 窗照切照補；
  縫內窗帶旗標才整組略過（= 舊 missingWindows 行為）；門楣一律發
  （= 舊 buildConfirmedDoorLeaves 行為）。grwsgs 重放：top-cap 19 → 29
  （+5 窗 +5 門）、door-lintel 0 → 5，全部頂線 272.5 對齊。
