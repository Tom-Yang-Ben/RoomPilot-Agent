# RoomPilot SQL 匯入器修改說明

## 修改目標

本版將資料來源責任固定為：

- 家具欄位：`furniture_official_catagory.json`
- GLB 資產：JSON `item_id/object_key` + upload result `delivery_url`
- 圖片資產：CSV `image_id/item_id/image_role/object_key/delivery_url`
- 向量：`furniture_embeddings_bge_m3.jsonl`

原始 JSON 不需要人工重整；匯入時才做正規化。

## 主要修改

1. SQL 正式分類改用 `category_final`，不再用 CSV `type` 或舊 `canonical_category_zh`。
2. 固定 56 種中文分類對應的 `category_code`，避免產生錯誤或帶 hash 的分類代碼。
3. `primary_color` 優先使用 `colors[0]`，缺少時才退回 `color`。
4. `primary_material` 優先使用 `materials[0]`，缺少時才退回 `material`。
5. `kind` 固定為 `furniture`。
6. `source` 從 JSON `object_key` 的 `models/{source}/furniture/...` 取得。
7. CSV 必填欄位縮減為資產關聯所需欄位，CSV 其他內容只保存於 staging/raw 欄位。
8. GLB 正式 `item_id/object_key` 以 JSON 為準，`delivery_url` 與 JSON `glb_url` 必須一致。
9. embedding source view 額外要求 `rag_indexable=true`。
10. embedding importer 使用共用 `parse_bool`，避免字串布林值被 Python `bool()` 誤判。
