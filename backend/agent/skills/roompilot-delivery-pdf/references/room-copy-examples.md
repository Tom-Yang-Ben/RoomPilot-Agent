# 空間文案：好壞對照

規則講再多都不如看實例。下面每組都是同一個空間、同一份資料，差別只在寫法。

## scene_line（生活場景句）

一句話，屋主在這個空間最日常的畫面。這是整頁最先被讀到的一行。

✗ 「打造溫馨舒適的家庭生活空間。」
　　誰都能寫，換哪個案子都成立，等於沒寫。

✓ 「週末早上你會端著咖啡坐在這裡，光從南面斜進來，小孩在地毯上玩不會被茶几擋住。」
　　有時間、有動作、有這個家的具體條件（南面採光、地毯、有小孩）。

✗ 「主臥是一天結束後的療癒空間。」
✓ 「關上門之後，房間裡唯一的光是床頭那盞可以調到最暗的燈。」
　　後者沒有講「療癒」兩個字，但讀的人自己感覺到了。形容詞讓讀者去下，效果比你替他下強。

## look（這個空間長什麼樣）

兩到四句。用一個人實際走進來的順序寫：先看到什麼、再注意到什麼、材質摸起來如何。

✗ 「客廳採用開放式設計，配置三人沙發一組、茶几一張、電視櫃一座，地板為木紋材質，整體風格簡約大方。」
　　這是家具清單分行寫。屋主看圖就知道有沙發，你要告訴他的是圖上看不出來的東西。

✓ 「從玄關轉進來，第一眼是整面南向的窗，沒有任何櫃體擋在光前面。沙發背對走道，正對窗，坐下來視線是往外的。地板是橡木海島型 (oak engineered)，色調比牆面深一階，赤腳踩起來不冰。電視收在側牆的淺櫃裡，不看的時候整面牆是乾淨的。」
　　有順序、有理由、有觸感、有「不看的時候」這種只有住的人才會想到的細節。

## rationale（為什麼這樣設計）

`title` 是一句判斷，`body` 是理由。理由必須接回屋主說過的話，或空間本身的客觀條件。

✗ title:「人性化設計」body:「充分考量使用者需求，打造符合人體工學的舒適空間。」
　　空的。這段話貼到任何一個案子都成立。

✓ title:「把電視牆讓給光」body:「你在問卷裡提到平常很少看電視，但很在意採光。所以我們沒有把電視放在南面主牆，那面牆整面留給窗；電視改收在側牆的淺櫃裡，深度只有 350 mm，不會壓縮走道。」
　　引用屋主自己的話 + 具體尺寸 + 說明代價。屋主無法反駁自己講過的需求。

✓ title:「走道留 90 公分」body:「餐桌到中島之間如果照原本的配置只剩 70 公分，兩個人錯身會卡住。我們把餐桌往窗邊挪了 20 公分，換來 90 公分的通道，代價是餐桌離廚房遠了半步。」
　　**寫出取捨**。承認代價會讓其他的優點變得可信。

找不到問卷依據時，退回空間的客觀條件（方位、開間、樑位、動線長度），不要編一個需求：

✓ title:「順著樑下做收納」body:「這個房間有一支橫樑壓在西側，淨高只剩 2.25 米。與其花錢包平，我們順著樑的深度做一整排到頂的衣櫃，樑就藏在櫃體裡，房間其餘部分維持 2.7 米。」

## specs（關鍵配置）

屋主拿來核對的表格，不是完整清單。三到六項。

✗ `{"label": "家具", "value": "沙發、茶几、電視櫃、地毯、單椅、邊几、立燈"}`
✓ `{"label": "主沙發", "value": "三人布沙發 2100 × 900 mm，離牆 150 mm"}`
✓ `{"label": "主通道淨寬", "value": "900 mm（沙發至餐桌）"}`
✓ `{"label": "地板", "value": "橡木海島型 (oak engineered)，色號待現場確認"}`
　　最後一項示範了怎麼標不確定：直接寫出來，不要跳過也不要編一個色號。

## hook（設計總論開場）

兩到三句，整份文件的第一段文字。從屋主的生活切入，不要從風格名詞切入。

✗ 「本案以日式現代 Japandi 風格為主軸，融合自然材質與極簡線條，營造出寧靜致遠的居住氛圍。」
　　風格說明書的開場。屋主不是來讀風格定義的。

✓ 「你們說希望回家的時候，眼睛可以休息一下。這個案子從頭到尾都在處理同一件事：把該收的收起來，把光留下來。28.6 坪不大，但只要視線不被擋住，它可以看起來比實際更深。」
　　用「你們說」開頭，把整份提案定錨在屋主自己的話上。最後一句給出一個具體的空間主張。

## 通用的三個地雷

**「奢華」「頂級」「極致」「質感」這類詞一個都不要用。** 這是一個真實的家，不是建案廣告。要表達貴氣就寫材質與工法，讀者自己會判斷。

**不要用「我們精心挑選」「悉心規劃」這種自我表揚。** 講你做了什麼判斷、代價是什麼，比說自己很用心有說服力得多。

**不要每個空間都用同一個句型開頭。** 八個房間都以「走進○○，首先映入眼簾的是……」開場，讀到第三個屋主就開始跳著看了。
