# 空間文案：好壞對照

規則講再多都不如看實例。下面每組都是同一個空間、同一份資料，差別只在寫法。

## scene_line（生活場景句）

一句話，屋主在這個空間最日常的畫面。這是整頁最先被讀到的一行。

✗ 「打造溫馨舒適的家庭生活空間。」
　　誰都能寫，換哪個案子都成立，等於沒寫。

✓ 「週末早上你會端著咖啡坐在這裡，光從南面斜進來，小孩在地毯上玩不會被茶几擋住。」
　　有時間、有動作、有這個家的具體條件（南面採光、地毯、有小孩）。

✗ 「主臥是一天結束後的療癒空間。」
✓ 「關上門之後，房間裡唯一的光是床頭那盞可以調到最暗的燈。」
　　後者沒有講「療癒」兩個字，但讀的人自己感覺到了。形容詞讓讀者去下，效果比你替他下強。

## look（這個空間長什麼樣）

兩到四句。用一個人實際走進來的順序寫：先看到什麼、再注意到什麼、材質摸起來如何。

✗ 「客廳採用開放式設計，配置三人沙發一組、茶几一張、電視櫃一座，地板為木紋材質，整體風格簡約大方。」
　　這是家具清單分行寫。屋主看圖就知道有沙發，你要告訴他的是圖上看不出來的東西。

✓ 「從玄關轉進來，第一眼是整面南向的窗，沒有任何櫃體擋在光前面。沙發背對走道，正對窗，坐下來視線是往外的。地板是橡木海島型 (oak engineered)，色調比牆面深一階，赤腳踩起來不冰。電視收在側牆的淺櫃裡，不看的時候整面牆是乾淨的。」
　　有順序、有理由、有觸感、有「不看的時候」這種只有住的人才會想到的細節。

✗ 「走進臥室會看到床 - Marca Amazon - Alkove - Hayes - Cama de matrimonio moderna de madera maciza con 4 niveles para el colchón (160 x 200 cm)、兩門滑動門衣櫃 - Amazon Brand - Movian Moselle 2-Door Wardrobe, 100 x 60 x 196 cm, Light Brown Oak-Effect/White。」
　　型號倒進敘述裡。屋主讀到第三個破折號就放棄了，而且他看圖就知道有一張床。**型號留在 `specs`**，敘述只用通用中文名。

✓ 「推開門，房間裡只有一張床和一整面到頂的衣櫃，其他都是空的。白牆配木地板，早上拉開窗簾的時候整個房間會亮起來——你說希望回家眼睛可以休息，這裡是全屋最安靜的一角。」
　　同樣的資料，講的是走進來會看到什麼、會有什麼感覺。

✗ 「全案沿用北歐 清新明亮的配色與材質方向，家具位置與走道淨空都經幾何引擎驗證，實際尺寸見下方規格表。」
　　三個問題：講製程（幾何引擎驗證）、講版面（見下方規格表）、而且這句話在八個空間裡一字不差各出現一次。全案共用的事實在總論與色彩章講一次就好。

## rationale（為什麼這樣設計）

第一條固定是「選件依據」，主軸是**什麼樣的設計判斷 → 所以選了什麼家具與材質 → 搭起來是什麼樣的空間感**。`body` 是理由，理由必須接回屋主說過的話，或空間本身的客觀條件。

✗ title:「人性化設計」body:「充分考量使用者需求，打造符合人體工學的舒適空間。」
　　空的。這段話貼到任何一個案子都成立。

✗ title:「擺位與淨空」body:「位置由幾何引擎計算與驗證：不重疊、留走道、不擋門窗。此配置即第 7 步鎖定的方案，圖面與清單一致。」
　　**這一條整條不要寫。** 家具放得下是我們的義務，不是設計理由；屋主看到「不重疊」只會想「不然呢」。

✓ title:「選件依據」body:「你提到很少開伙但常在家吃早餐，所以餐桌選 130 公分的四人尺寸，不做中島。桌面是實木、椅子是布面加黃銅腳，兩種材質就收住了；件數壓下來，站在門口一眼看得完，房間會比實際看起來深。」
　　設計判斷（用途決定尺寸）→ 選了什麼（尺寸、材質）→ 空間感（一眼看得完）。

✓ title:「把電視牆讓給光」body:「你在問卷裡提到平常很少看電視，但很在意採光。所以我們沒有把電視放在南面主牆，那面牆整面留給窗；電視改收在側牆的淺櫃裡，深度只有 350 mm，不會壓縮走道。」
　　引用屋主自己的話 + 具體尺寸 + 說明代價。屋主無法反駁自己講過的需求。

✓ title:「走道留 90 公分」body:「餐桌到中島之間如果照原本的配置只剩 70 公分，兩個人錯身會卡住。我們把餐桌往窗邊挪了 20 公分，換來 90 公分的通道，代價是餐桌離廚房遠了半步。」
　　**寫出取捨**。承認代價會讓其他的優點變得可信。

找不到問卷依據時，退回空間的客觀條件（方位、開間、樑位、動線長度），不要編一個需求：

✓ title:「順著樑下做收納」body:「這個房間有一支橫樑壓在西側，淨高只剩 2.25 米。與其花錢包平，我們順著樑的深度做一整排到頂的衣櫃，樑就藏在櫃體裡，房間其餘部分維持 2.7 米。」

## specs（關鍵配置）

屋主拿來核對的表格，不是完整清單。三到六項。這裡是**唯一**該出現型號與品牌的地方。

✗ `{"label": "家具", "value": "沙發、茶几、電視櫃、地毯、單椅、邊几、立燈"}`
✓ `{"label": "主沙發", "value": "三人布沙發 2100 × 900 mm，離牆 150 mm"}`
✓ `{"label": "主通道淨寬", "value": "900 mm（沙發至餐桌）"}`
✓ `{"label": "地板", "value": "橡木海島型 (oak engineered)，色號待現場確認"}`
　　最後一項示範了怎麼標不確定：直接寫出來，不要跳過也不要編一個色號。

**同款同尺寸合併成一列。** 四張一樣的餐椅抄四遍，屋主第一反應是「這表格是不是壞了」。

✗ 三列一模一樣的 `{"label": "鉚釘現代餐椅，34 英寸…粉筆色", "value": "dining-chair，51×52 cm，黃銅"}`
✓ `{"label": "鉚釘現代餐椅，34 英寸（約 86.4 釐米）高, 粉筆色", "value": "餐椅，51×52 cm，黃銅，共 3 件"}`
　　順帶一提：`value` 開頭的類型要用中文（餐椅），不是 `dining-chair`。

## statement.pillars（設計總論）

`pillars` 是**後續每一章的摘要**，章名當 `title`，`body` 約 50 字。

✗ title:「位置經過驗證」body:「每件家具的位置都由幾何引擎計算與驗證：不重疊、留走道、不擋門窗。圖面上看到的就是可以放得下的方案。」
　　這是製程說明，而且不對應任何一章。屋主翻開第一頁想知道的是「這份文件裡有什麼」。

✓ title:「客廳」body:「約 4.2 × 3.6 米，放沙發、茶几、電視櫃。材質以布面與木材為主，電視收在側牆的淺櫃裡。」
✓ title:「色彩與材質」body:「『清新明亮』色卡的三個顏色怎麼分配：米白主色、淺綠輔色、霧綠點綴；地板與牆面全室同一款。」

每章一條，八個空間就八條加三條（速覽、色彩、接下來）。不要在每條尾巴加「該章有這個空間的樣貌、選件依據與規格表」——講完第一次就沒有資訊量了。

## palette（色彩與材質）

只有三個色塊配三行字，這一章會像沒寫完。

✗ `{"hex": "#F7F5ED", "name": "#F7F5ED", "usage": "主色（60%）"}`
　　`name` 印色碼等於沒有名字。屋主看到的是一串亂碼。

✓ `{"hex": "#F7F5ED", "name": "米白 #F7F5ED", "usage": "主色｜牆面、天花與大面櫃體"}`
　　中文色名在前、色碼在後（發包時還是要色碼）；`usage` 講清楚落在哪些部位。

`intro` 要寫三段：60／30／10 怎麼分配、三個顏色各自的位置、地板牆面怎麼跟它搭。`materials[].why` 每一列都要有理由——「全室同一款，房間之間沒有段差」比空白有用得多。

## hook（設計總論開場）

兩到三句，整份文件的第一段文字。從屋主的生活切入，不要從風格名詞切入。

✗ 「本案以日式現代 Japandi 風格為主軸，融合自然材質與極簡線條，營造出寧靜致遠的居住氛圍。」
　　風格說明書的開場。屋主不是來讀風格定義的。

✓ 「你們說希望回家的時候，眼睛可以休息一下。這個案子從頭到尾都在處理同一件事：把該收的收起來，把光留下來。28.6 坪不大，但只要視線不被擋住，它可以看起來比實際更深。」
　　用「你們說」開頭，把整份提案定錨在屋主自己的話上。最後一句給出一個具體的空間主張。

## 通用的三個地雷

**「奢華」「頂級」「極致」「質感」這類詞一個都不要用。** 這是一個真實的家，不是建案廣告。要表達貴氣就寫材質與工法，讀者自己會判斷。

**不要用「我們精心挑選」「悉心規劃」這種自我表揚。** 講你做了什麼判斷、代價是什麼，比說自己很用心有說服力得多。

**不要每個空間都用同一個句型開頭。** 八個房間都以「走進○○，首先映入眼簾的是……」開場，讀到第三個屋主就開始跳著看了。
