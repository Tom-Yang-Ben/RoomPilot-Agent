# 設計規範與 token

實際的值在 `assets/tokens.css`（CSS 變數）與 `assets/report.css`（版面規則）。這份文件說明為什麼是這些值，以及要換品牌時該改哪裡。

## 為什麼要有 token

因為每一份交付文件都必須長得一樣。屋主可能同時收到你和另外兩家的提案；三份文件擺在桌上，視覺一致、排版穩定的那份看起來就是比較可靠。把顏色和字級抽成變數，是為了讓「一致」變成預設值，而不是每次靠人記得。

實務上的規則只有一條：**不要在 `build_pdf.py` 或 `content.json` 裡寫死顏色與字級**，一律走 CSS 變數。要調整就改 `tokens.css`，一次改到所有文件。

## 色票

| Token | 值 | 用途 |
|---|---|---|
| `--ink-900` | `#1C1917` | 主標題、封面大字 |
| `--ink-700` | `#44403C` | 內文 |
| `--ink-500` | `#78716C` | 次要說明、圖說 |
| `--ink-300` | `#A8A29E` | 標籤、頁碼 |
| `--line` | `#E7E2DC` | 分隔線、表格線 |
| `--paper` | `#FFFFFF` | 頁面底 |
| `--paper-alt` | `#FAF7F2` | 區塊底色 |
| `--accent` | `#A9744F` | 章節編號、重點 |
| `--accent-soft` | `#EFE3D8` | 生活場景句的底色 |
| `--note` | `#4D7C5A` | 正面提示 |
| `--warn` | `#B4552F` | 限制、待確認 |

底色刻意不是純白（`--paper-alt` 帶暖）：室內設計提案通篇是木質與布料的照片，純冷白的區塊會跟照片打架。焦糖棕 `--accent` 是全篇唯一的彩色，用在章節編號和重點，出現頻率低才有重量。

**禁用**：飽和度高的藍、綠、紫，以及任何漸層。渲染圖本身已經很有顏色，版面再加色就變成兩件事在搶注意力。

## 字型與字級

標題用襯線（`Georgia` / `Noto Serif CJK TC`），內文用黑體（`Inter` / `Noto Sans CJK TC`）。這組合在室內設計與建築提案裡幾乎是預設值——襯線給提案一點編輯感，黑體讓長段中文好讀。

英文與數字排在中文字型前面，是為了讓 `2100 × 900 mm`、`oak engineered` 這類專有名詞用比例更好的西文字形，中文才 fallback 到 Noto CJK。

| Token | 值 | 用途 |
|---|---|---|
| `--fs-cover` | 40pt | 封面案名 |
| `--fs-h1` | 24pt | 章節標題 |
| `--fs-h2` | 17pt | 空間名 |
| `--fs-h3` | 11.5pt | 小標 |
| `--fs-lead` | 12pt | 引言、生活場景句 |
| `--fs-body` | 10pt | 內文 |
| `--fs-caption` | 8.5pt | 圖說、規格表 |
| `--fs-label` | 7.5pt | 全大寫標籤 |

內文行高 `--lh-body: 1.85`。中文方塊字沒有 x-height 的高低起伏，用英文習慣的 1.5 會擠得讀不下去。這個值不要往下調。

## 間距與版面

間距走 4pt 基準（`--sp-1` 到 `--sp-8`），不要出現 `13pt`、`7pt` 這種不在階梯上的值。頁面邊界 18mm——A4 的中文提案再窄會顯得廉價，再寬正文欄寬會不夠。

圓角：主視覺大圖是**方角**（`--r-none`），像雜誌跨頁；只有色塊、標籤、卡片用 2–4pt 的小圓角。渲染圖加圓角會有一種簡報範本的廉價感。

## 換成別的品牌

改 `assets/tokens.css` 就好，`report.css` 通常不用動。順序建議：

先換 `--accent` 與 `--accent-soft`（品牌主色與其淡版），再換 `--paper-alt`（要跟主色同一個色溫），最後看情況換 `--font-display`。`--ink-*` 那組灰階除非品牌有特別規定，否則留著——那組是為了在紙上和螢幕上都有足夠對比而選的。

換完跑一次 `build_pdf.py` 看實際輸出。特別檢查生活場景句的底色（`--accent-soft`）上面的文字還讀不讀得清楚，那是最容易翻車的地方。
