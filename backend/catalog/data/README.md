# Public catalog data

This directory contains only small project-authored metadata used by the portable profile:

- `portable_furniture.json`: procedural furniture dimensions and placement metadata.
- `surface_catalog.json`: procedural solid-color surfaces.
- `taiwan_style_cards.json` and `furniture_catalog_6styles_zh.json`: presentation vocabulary without bundled product assets.

No product catalog, GLB, product image, cloud manifest, embedding, quarantine payload or database dump is part of the public repository. Full-profile developers supply their own licensed PostgreSQL data; see `docs/FULL_PROFILE.md`.
