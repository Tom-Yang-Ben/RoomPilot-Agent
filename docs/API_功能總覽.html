RoomPilot API 功能總覽

整理日期：2026-08-01（分支 yen）。所有端點皆定義於 backend/server/main.py，無外部 APIRouter、無 WebSocket。共 44 個端點：4 個頁面路由 + 40 個 API。

  • 框架：FastAPI；startup 時執行 warm_catalog_cache() 預熱型錄快取。
  • 靜態掛載：/static → backend/server/static（CSS/JS/HTML/GLB 樣本）；/docs-assets → static/moodboard_assets（moodboard 與色卡圖）。
  • 大小限制：渲染 PNG 上限 20 MB；workflow payload 上限 2 MB。平面圖支援 .dxf/.png/.jpg/.jpeg。
  • 單位規則：跨模組幾何一律公分（_cm 欄位），payload 帶 coordinate_unit: "cm" 與 schema_version；面積用 _m2。

工作流程步驟（WORKFLOW_STEPS）

project → upload → recognition → calibration → space_confirmation → requirements → layout_2d → white_model_3d → realistic_3d → proposal_review → ai_render
