# IKEA-Dataset 下載檢查表

最後更新：2026-06-28

使用方式：

1. 先只看客廳包：`Living Room 1.zip`、`Living Room2.zip`
2. 每種家具先找 1 到 3 張最乾淨的圖
3. 不要急著多抓，先把主樣本挑準
4. 每挑到一張，就照下面逐項勾選

## 共同檢查項

### 圖片品質

- [ ] 家具主體清楚
- [ ] 輪廓容易辨識
- [ ] 沒有被嚴重裁切
- [ ] 沒有太多遮擋
- [ ] 沒有過暗或過曝
- [ ] 不是強反光或極度雜亂背景

### 資料可用性

- [ ] 有尺寸描述
- [ ] 能判斷正面 / 側面 / 三分之二視角
- [ ] 底部大致看得懂
- [ ] 適合之後做 3D 生成

## 沙發

- [ ] 2 到 3 人座
- [ ] 扶手明顯
- [ ] 靠背清楚
- [ ] 坐墊輪廓完整
- [ ] 不要先選 L 型太複雜款
- [ ] 不要先選遮擋太多款

## 扶手椅

- [ ] 單椅型
- [ ] 扶手清楚
- [ ] 背靠高度分明
- [ ] 輪廓完整
- [ ] 結構不要太花

## 單人椅

- [ ] 椅腳清楚
- [ ] 椅面清楚
- [ ] 背靠清楚
- [ ] 結構簡單
- [ ] 方便後續接地與校正

## 茶几

- [ ] 桌面平整
- [ ] 桌腳簡單
- [ ] 長寬比例清楚
- [ ] 輪廓容易看懂
- [ ] 不要先選太多裝飾

## 邊几

- [ ] 尺寸較小
- [ ] 方形或圓形輪廓明確
- [ ] 容易和沙發搭配
- [ ] 結構簡單

## 電視櫃

- [ ] 長條型
- [ ] 水平感明顯
- [ ] 底部接地清楚
- [ ] 抽屜 / 櫃門層次不會太碎

## 書櫃

- [ ] 垂直高度明顯
- [ ] 層板結構清楚
- [ ] 不是過滿展示款
- [ ] 架構容易做成 3D

## 收納櫃

- [ ] 盒型清楚
- [ ] 正面平整
- [ ] 適合做體積包圍盒
- [ ] 不是過度細碎造型

## 腳凳

- [ ] 低矮
- [ ] 單體簡單
- [ ] 底部容易辨識
- [ ] 輪廓完整

## 層架 / 展示櫃

- [ ] 架構直線感強
- [ ] 層板清楚
- [ ] 不要先選內容物太雜的圖
- [ ] 適合後續空間填充

## 建議每類先挑數量

- 沙發：1 主樣本 + 2 備樣本
- 扶手椅：1 主樣本 + 1 到 2 備樣本
- 單人椅：1 主樣本 + 1 備樣本
- 茶几：1 主樣本 + 1 備樣本
- 邊几：1 主樣本 + 1 備樣本
- 電視櫃：1 主樣本 + 1 備樣本
- 書櫃：1 主樣本 + 1 備樣本
- 收納櫃：1 主樣本 + 1 備樣本
- 腳凳：1 主樣本 + 1 備樣本
- 層架 / 展示櫃：1 主樣本 + 1 備樣本

## 合格後命名

```text
{category}_ikea_{item_id}_source.jpg
{category}_ikea_{item_id}_raw.glb
{category}_ikea_{item_id}_normalized.glb
{category}_ikea_{item_id}.json
```

## 不合格就先放棄

- [ ] 遮擋太多
- [ ] 背景太亂
- [ ] 底部看不懂
- [ ] 家具主體不完整
- [ ] 尺寸資訊缺失
- [ ] 外型太怪，不適合當第一批主樣本
