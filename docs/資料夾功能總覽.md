# Repository map

| Path | Purpose |
|---|---|
| `backend/server/` | FastAPI、SQLite 專案保存、八步 workflow 與 API adapters |
| `backend/server/static/` | 唯一正式 HTML/CSS/JS/Three.js 前端 |
| `backend/floorplan/` | PNG/JPG/DXF 辨識與 `layout_json` |
| `backend/spatial_data/` | 空間 evaluation 與家具檢索證據 |
| `backend/catalog/` | portable fixture 與 PostgreSQL read repository |
| `backend/agent/` | 需求結構化、選件與說明 |
| `backend/engine/` | 家具擺放、碰撞、淨空與合法性 |
| `backend/upgrade3d/` | 已確認 layout/DXF 的 3D 結構轉換 |
| `examples/fixtures/` | 可重建、匿名且有 provenance 的公開 fixture |
| `tests/` | 單元、API、契約、browser 與 opt-in PostgreSQL 測試 |
| `docs/` | 現行開發文件與標明為歷史的設計紀錄 |
| `scripts/` | 公開檢查、fixture、static hash 與資料庫工具 |

`.runtime/`、`.tmp/`、模型、使用者檔案、資料庫 dump、商品資產與 cache 都不進 Git。正式前端沒有第二套 React source tree。
