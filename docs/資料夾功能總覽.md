# RoomPilot 資料夾功能總覽

本文件是目前專案的目錄導覽。新成員應先看本文件，再進入對應模組。

| 資料夾 | 功能 | 主要入口／注意事項 |
|---|---|---|
| `roompilot/` | Python 主套件 | 所有正式後端與演算法都在此處。 |
| `roompilot/catalog/` | 家具型錄轉接與資料 | `style_db.py` 是尺寸單位的邊界；不要在其他模組做 cm→m。 |
| `roompilot/catalog/data/` | 執行期 JSON 資料 | 新型錄是 `furniture_catalog_6styles_zh.json`，只使用六種正式風格。 |
| `roompilot/catalog/data/舊友：12種風格與JSON/` | 舊資料封存 | 只供追溯 12 風格與舊外部索引，不得由執行期載入。 |
| `roompilot/engine/` | 家具擺放與碰撞檢查 | 家具座標唯一權威；包含淨空、牆邊距與房間合法性。 |
| `roompilot/upgrade3d/` | DXF 解析與 3D 白模資料 | `dxf_parser.py` 將 DXF 轉為房間、牆、門窗資料。 |
| `roompilot/floorplan/` | 平面圖 PNG→DXF 管線 | 包含牆正交化及門窗偵測評估。 |
| `roompilot/server/` | FastAPI 與場景服務 | `main.py` 是唯一 API 入口；`scene_service.py` 編排選品與擺放。 |
| `roompilot/server/static/` | 網站前端資產 | `/library` 用分頁型錄 API；3D viewer 由 Three.js 模組組成。 |
| `roompilot/skills/` | 專案內 Agent 技能 | 與產品功能相關的提示詞／工作流資料。 |
| `frontend3d/` | 獨立 R3F 編輯器 | F6 拖曳邏輯的參考與實驗區；正式展示頁仍在 server static。 |
| `scripts/` | 資料維護與匯入工具 | `build_six_style_catalog.py` 重建六風格中文型錄並封存舊資料。 |
| `tests/` | 自動化測試 | 新增功能應在此補足公開 API 或資料契約驗證。 |
| `docs/` | 規格、決策、交接與稽核 | SSOT 為 `RoomPilot_現行版本總覽.md`。 |
| `examples/` | 退役原型與介面範例 | 不作為正式執行期流程依賴。 |
| `dataset/` | 已下載的 GLB 素材 | 大型資產；新檔案進版控前需先確認。 |
| `testdata/` | DXF、PNG、GLB 等測試素材 | 供 parser、viewer 與單元測試使用。 |
| `furniture_engine/` | 舊版／獨立引擎參考 | 正式程式已整合至 `roompilot/engine/`。 |
| `sf3d/`、`style-rag/`、`web_fastapi/` | 歷史資料與整合來源 | 僅在需要比對舊流程或補素材時參考，不是主線。 |

## 型錄資料流

`舊 12 風格 JSON` → `scripts/build_six_style_catalog.py` → `furniture_catalog_6styles_zh.json` → `roompilot.server.main` → `/api/furniture` 分頁 API → 家具資料庫頁與場景選品。

模型是否可載入不是 JSON 的宣告值，而是 server 依實際本機 GLB、可讀 ZIP entry 或遠端 GLB URL 驗證後決定。
