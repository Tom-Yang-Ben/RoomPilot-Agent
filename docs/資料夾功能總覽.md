# RoomPilot 資料夾功能總覽

> 2026-07-21 依實際工作樹重新建立。這份文件只回答「目前留下來的東西做什麼」；功能狀態、P0 與分工以 `docs/01_專題進度/RoomPilot_現行版本總覽.md` 為準。

## 1. 專案入口

- 唯一後端:`backend.server.main:app`
- 唯一使用者入口:`http://localhost:8002/scene`
- React 原始碼:`frontend/`
- FastAPI 實際交付的前端建置:`backend/server/static/frontend3d/`

```bash
uv run --extra vision uvicorn backend.server.main:app --port 8002
# 或用 Docker 一次起完整堆疊（同一個入口、同一個網址）：docker compose up -d
```

使用者不需要另外開啟 5173；Vite dev server 只供前端開發。

## 2. 頂層目錄

| 路徑 | 現行用途 | 是否執行期需要 |
|---|---|---|

| `frontend/` | 專案建立到 3D 提案的 React/R3F 原始碼 | 建置時 |

| `scripts/` | IKEA 型錄下載、清洗、驗證與匯入工具 | 維運時 |

根目錄的 `README.md` 是啟動入口，`AGENTS.md`／`CLAUDE.md` 是 AI 協作與架構限制，`pyproject.toml`／`uv.lock` 是 Python 依賴正本。

## 3. `backend/` 模組(原 `roompilot/`)

| 路徑 | 職責 |
|---|---|
| `engine/` | 家具座標唯一權威；碰撞、房間邊界、淨空與調整 |
| `floorplan/` | PNG/JPG/BMP 辨識牆、門窗並輸出 DXF／交接資料 |
| `upgrade3d/` | DXF 轉樓面 JSON、牆體與真實門窗開口 |
| `agent/` | `layout_intent` 與 `recovery`；只給語意提示，不計算座標 |
| `catalog/` | 家具型錄、風格與引擎資料轉接 |
| `skills/` | LLM intake／推薦行為規格；目前不是 runtime import |
| `server/` | 唯一 FastAPI、專案 SQLite、問卷、2D 配置、場景與靜態網站 |

單位與座標系不可由本文件簡化；修改前讀 `CLAUDE.md` 的 Architecture invariants。

## 5. 本機但不進 Git

| 路徑 | 原因 |
|---|---|
| `.env` | OpenRouter 等本機密鑰；不得提交 |
| `.venv/` | uv/Python 執行環境，可重建 |
| `frontend/node_modules/` | npm 依賴，可重建 |
| `backend/floorplan/models/*.onnx` | 影像辨識權重；執行 vision 流程需要 |
| `.runtime/` | Server 啟動後自動建立的專案 DB、上傳與渲染紀錄 |

`.runtime/` 不屬於原始碼。搬走或刪除會讓 8002 的專案清單回到全新狀態，但不會破壞程式；下次啟動會自動重建。

## 6. 驗證

```bash
uv run pytest tests/ -v
cd frontend
npm test
npm run build
```

前端測試與建置成功仍不等於畫面正確。涉及操作流程、3D、門窗或家具時，必須回到 `:8002/scene` 走完整使用者路徑。

## 7. 清理邊界

- 可以清:`__pycache__/`、`.pytest_cache/`、`.DS_Store`、舊 `frontend/dist/`。
- 不可當快取清:`backend/server/static/frontend3d/`、`data/testdata/pngans/`、`data/dataset/`、`backend/floorplan/models/`。
- 新增頂層目錄、大型模型或整包外部 repo 前，先依 `CLAUDE.md` 的入倉規則確認。
