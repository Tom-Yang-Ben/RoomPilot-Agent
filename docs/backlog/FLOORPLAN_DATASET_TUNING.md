# 平面圖辨識資料集調校

## 狀態

待執行。此文件保留原 `FV-07` 尚未完成的資料集與辨識率評估工作。

## 目標

- 蒐集具有合法使用權的真實平面圖，並記錄來源、格式與標註狀態。
- 建立固定的訓練、驗證與測試資料切分，避免同一案場出現在不同切分。
- 評估比例尺誤差、牆體拓樸、門窗辨識與房間名稱辨識。
- 保留人工確認關卡；低信心或無法判定的結果不得直接進入後續 3D 流程。

## 單位與輸出契約

- 影像處理內部可使用像素座標。
- 對外輸出的平面幾何、長度與位置統一使用公分。
- 面積使用平方公尺顯示時，必須由公分幾何換算，不得混用舊的公尺座標契約。
- 每筆輸出應保留比例尺來源與信心資訊，讓前端可以提示使用者校正。

## 評估項目

1. 比例尺：量測預測長度相對於標註長度的誤差。
2. 牆體：檢查牆線位置、連通性、封閉房間與多餘／遺漏牆段。
3. 門窗：分別計算 precision、recall 與 F1，並檢查其所在牆段及寬度誤差。
4. 房間語意：計算房間名稱正確率，另列無法辨識與錯誤配對案例。
5. 流程成功率：統計從影像分析、人工確認到產生可用平面幾何的完整成功比例。

## 驗收產物

- 可追溯來源與授權狀態的資料清單。
- 固定版本的測試集及標註格式。
- 各項指標的基準結果與失敗案例分類。
- 調校前後的比較報告。
- 不通過信心門檻時仍會要求人工確認的自動化測試。
