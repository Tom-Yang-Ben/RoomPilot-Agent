# 資產與資料政策

公開 repository 只接受下列內容：

- 團隊自行建立、可重建的匿名 fixture。
- 可證明允許再散布的第三方檔案，並附作者、來源網址、授權、版本與 checksum。
- 小於 repository guard 限制且確實為 runtime／測試必要的檔案。

不得提交商品型錄、使用者專案、資料庫 dump、模型權重、抓取圖片、來源不明 GLB、生成 cache 或只有「可在網頁觀看」但沒有再散布授權的素材。品牌名稱只可用於相容性／來源說明，不代表合作或背書。

目前 bundled third-party runtime 僅為 MIT 授權的 Three.js 0.165.0；其聲明見 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。程序化家具、色卡、材質與匿名範例由 AIPE03 第四組建立，隨程式以 GPL-3.0-or-later 散布。
