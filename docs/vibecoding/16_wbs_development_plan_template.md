## 2. WBS 結構

模板原始骨架（2.0 資料庫設計、3.0 後端、4.0 前端、6.0 部署上線）對本專案多數不適用——本專案為純 Python CLI 管線，無 Web 後端、無資料庫、無 REST API。對應關係：

- **資料庫設計 → N/A**：本專案「資料層」是檔案型資料資產（Identify_ans/、cubicasa/room/ npz 快取、json/eval_rooms/ 報表），其擴充工作編入 5.0 / 6.0。
- **前端開發 → N/A**：唯一面向使用者的視覺產物是 recognition_report.html（根目錄、支援深色模式）與 chk/ 檢核圖，維護工作併入 1.0。
- **部署上線 → N/A**：無伺服器部署；「部署」＝clone repo＋設 GITHUB_TOKEN 環境變數，權重 model_finetuned_v5.pkl 自 GitHub Release `weights-v5` 自動下載＋SHA-256 校驗（floorplan2room.py `_ensure_cc_weights`，已完成，7 例單元測試）。故不設部署模組。

以下為依 v2.16 優先序展開的真實 WBS：
