# 監督式分割頭（彩色房間分割）設計書

- **日期**: 2026-08-03（使用者裁定：走監督式分割模型，然後接灰階側）
- **背景**: 白牆萃取品質輪三角度量測（手工 0.617/帶級 DINO 0.67/全域結構
  0.64）證明「牆帶」中間表徵是彩色棄守畫風的原理瓶頸——局部同構、全域被
  門洞打穿。監督式分割頭跳過牆帶表徵，直接從 GT 學「房間內部 vs 邊界」。
- **量尺紀律**:
  - 訓練資料只用 own_dataset_color 19 張；**own_eval_color 9 張絕不進訓練**。
  - dev 量測一律留一張（LOIO）：評 floor_X 時用其餘 18 張訓的頭，防洩漏。
  - 出貨頭用 19 張全訓，其真實成績以 holdout 判定（dev 數字另註口徑）。

## 三階段

### 階段 0 — 可分性標定（離線）

新工具 `training/scripts/probe_seg_head.py`：
1. 19 張彩 dev：1x bgr resize 到 14 倍數，DINOv2 ViT-S/14 整圖前向取
   patch 特徵格（C=384）。
2. 標籤：GT 房間聯集 mask 下採樣到 patch 格，內部佔比 >0.5 ＝房內。
3. LOIO 線性頭（logistic per patch）：patch AUC／IoU 逐張報告，
   重點看棄守張 07/08/09 的邊界是否浮現（牆 10~20px vs patch 14px
   是主風險）。
4. 產出 `temp/json/seg_head_probe.json`＋預測圖 `temp/seg_head/`。

**閘門**：棄守張的房間邊界在預測圖上可辨（патch IoU ≥0.80 全集、
目視邊界成形）才進階段 1；不足則試 2x 輸入/多層特徵變體。

### 階段 1 — 房間實例化與管線接入

- patch 機率圖 → 上採樣 → 閾值 → 連通元件 → 直角化（軸對齊約束）
  → 房間 proposals。
- 接入面：彩管線災難張路徑的**替代分割源**（與白牆救援輪同位階、
  A/B 擇優採用），正常張零接觸。
- 出貨資產 `backend/floorplan/seg_head.npz`（缺檔＝停用、行為不變）。

### 階段 2 — A/B 收割

彩 dev 逐張（LOIO 口徑）、灰 dev 零接觸確認、holdout 收尾。

## 風險

- 19 張過擬合 → LOIO 把關；頭維持線性（384→1）。
- 牆細於 patch → 混合 patch 邊界模糊；備援：2x 輸入、相鄰 patch 差分。
- 房間實例化（連通元件→直角化）是新幾何管線，直角約束沿專案鐵律。
