# 帶級 DINO 語意判別（白牆萃取品質輪）設計書

- **日期**: 2026-08-02（深夜，使用者已核准設計）
- **背景**: 色塊分割大工程線。彩圖白牆萃取的「真牆帶 vs 假帶」判定是棄守
  三張（color_floor_07/08/09 殘餘 13 間）、彩門縫品質（P 0.38）與彩窗上游
  的共同根因。既有帶級手工特徵（兩側同色相桶/平行近鄰/端接暗牆網）已實測
  五五開收案（floor_09 診斷輪）；「整房 DINO 信心」粒度太粗且反向。
  **帶級語意粒度未試過**，DINO 對材質語意（牆/木紋/磁磚）是強項（分域雙頭
  輪已證）。
- **使用者裁定**: 主量尺＝彩 dev 總分（75.0% → 78%+），不設止損、打到沒
  彈藥為止。方向 A（帶級 DINO），手工特徵併進判別器當配角；若 DINO 維度
  也五五開，回報後轉 B（牆網圖全域最佳化）。

## 三階段

### 階段 0 — 離線可分性標定（先量再做）

新工具 `training/scripts/probe_band_semantics.py`：

1. 19 張彩 dev 逐張跑管線到白帶候選生成點（直接呼叫 fp_c 的白帶生成，
   不改管線）。
2. GT 弱標籤：帶身像素 ≥70% 落在任一 GT 房多邊形內＝**假帶**；≤30%
   （帶在房間夾縫廊道）＝**真牆帶**；30~70% 棄標。
3. 逐帶特徵：
   - DINO：帶身沿中線多點取樣 patch 向量＋兩側翼（±帶厚偏移）取樣，
     mean 聚合成帶身/側翼向量（座標對齊彩管線 2x）。
   - 手工（配角）：長厚比、側翼色度統計、暗牆網端接數、帶厚/T 比。
4. 判別器：線性 logistic probe，**留一張交叉驗證**（19 fold）量 AUC，
   分組報告 DINO 單獨／手工單獨／合併。
5. 產出 `temp/json/band_semantics.json`（逐帶明細＋分組 AUC）。

**閘門**：合併 AUC 明顯優於既有五五開（≥0.65 為工作線）才進階段 1；
否則彈藥未盡前先試特徵變體（取樣密度/聚合方式/側翼距離），變體也不可分
即回報使用者轉 B。

### 階段 1 — 管線接入（外科）

- probe 權重出貨 `backend/floorplan/band_probe.npz`（比照 room_head 慣例，
  推論期零 GT 依賴）。
- 接口：`band_semantic_score(bands, bgr, ...) -> scores`，接進白牆**救援輪**
  帶過濾（增強/取代 55% 覆蓋閘與假帶三特徵）。外科原則：只動災難張/救援
  採用路徑，正常張零接觸。
- 門檻由 dev 逐張 A/B 定，遵守「災難張限定、正常張零退化」承諾。

### 階段 2 — 收割與收尾

- 縫合輪/證據刀在乾淨帶集上自然重跑（機制既有，不另改）。
- 彩 dev 逐張 A/B（主量尺）；灰 dev 跑一次確認零接觸（白牆線不走灰路）；
  循環收尾補 holdout；plan/Readme 帳面。

## 元件與資料流

```
白帶候選(fp_c) ──(2x座標)──▶ DINO patch 取樣 ──▶ 帶特徵 ──▶ probe 分數
                                                    ▲
GT 弱標籤(僅離線標定) ──────────────────────────────┘
                probe 權重 band_probe.npz（推論期資產）
```

- DINO backbone 重用管線既有載入（不另載模型）。
- 測試：弱標籤器與特徵切片 TDD（合成帶＋合成 GT）；接入後 A/B 實測。

## 風險

- DINO patch 14px 粒度對細帶偏粗——多點取樣＋側翼對比補償；2x 座標有利。
- 19 張過擬合——留一張 CV 把關；權重出貨前不看 holdout。
- 救援輪行為耦合——接入面收窄成單一過濾函式，行為契約測試釘住。
