# 3D scene construction

現行流程由 `backend/upgrade3d/`、`backend/server/scene_service.py`、`backend/engine/` 與 `backend/server/static/scene_viewer.js` 組成：

```text
confirmed layout_json / DXF (cm)
  -> wall, opening and room geometry
  -> engine-validated furniture placement
  -> scene_json (cm)
  -> local Three.js viewer
```

viewer 只呈現後端幾何與使用者編輯結果，不自行重做碰撞或淨空裁決。portable 家具使用 `procedural_fixture` 方塊；full profile 的 GLB URL 必須來自開發者提供且已確認授權的 catalog。詳細資料邊界見 [Architecture](ARCHITECTURE.md) 與 [layout/scene contract](contracts/LAYOUT_SCENE_BOUNDARY_CONTRACT.md)。
