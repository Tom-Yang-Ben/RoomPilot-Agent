# Web UI 狀態

最後更新：2026-07-06

## 目前頁面

1. `/` 首頁
2. `/styles` 風格展示頁
3. `/library` 家具資料庫頁
4. `/scene` 3D 場景展示頁

## UI 共通規則

1. 介面以中文為主。
2. 全站導覽統一為 RoomPilot 風格 header。
3. 背景維持黑底、發光粒子與柔焦氛圍，不再改成整頁淺底。
4. 主要內容框體使用淺色卡片，與背景做明確分層。
5. 3D viewer 要清楚標示 XYZ 正負方向。
6. 使用者看到的是「風格、家具、場景」，不是後端 JSON。

## 首頁狀態

1. 首頁已改成 RoomPilot 風格 hero。
2. 主視覺包含：
   - 大標題
   - 主說明文字
   - `開始設計` CTA
   - `觀看風格` CTA
   - 功能列
   - 五步流程
3. 舊版小型「前往 3D 場景展示」結果卡已移除。
4. 上方功能卡 hover / focus 時，會連動下方流程卡浮起高亮。
5. 首頁背景保留黑底發光與粒子效果，內容卡才是淺色。

## `/styles` 頁面狀態

1. 已移除右側 `DATABASE GROUPING / 資料庫對應家具分類` 側欄。
2. 頁面主體聚焦在 12 種風格本身。
3. 風格主圖放在 `web_fastapi/static/style_images/`。
4. 主圖改為橫向主視覺優先，降低裁切。
5. 圖上標註改成以畫面元素為主，不再用大段說明文字覆蓋主圖。
6. 已補上：
   - 關鍵字
   - 主色
   - 材質
   - 造型特徵
   - 不要的元素
   - 空間背景
   - 牆面推薦
   - 地板推薦
   - 推薦搭配組合
7. 目前仍需持續人工校正少數風格圖的標註位置與圖文對應。

## `/library` 頁面狀態

1. 家具資料卡已全面中文化。
2. 支援搜尋、風格篩選、類型篩選。
3. 每頁目前為 21 筆。
4. 分頁改成前 5 頁與最後 3 頁，中間以 `...` 省略。
5. 家具卡預覽圖已優先改為 GLB 即時渲染縮圖，而不是簡化示意圖。
6. 點選家具時，右側 viewer 會同步切換。
7. viewer 背景會依家具深淺自動切換，讓模型更容易辨識。
8. viewer 控制按鈕已加強對比，讓 `重設視角` 等操作更明顯。

## `/scene` 頁面狀態

1. 已從說明頁轉成可操作的正式流程頁。
2. 目前採用單欄流程：
   - 上半部條件設定
   - 下半部 3D 結果
3. 目前條件設定已再精簡成下拉選項為主，不再讓表單區與結果區各自有滾輪。
4. 家具挑選改成「家具組合」下拉方式，避免主畫面一次展開過多勾選項。
5. 結果區集中顯示：
   - 3D viewer
   - 場景摘要
   - 已選家具
   - 替換 / 移除 / 新增 / 重排操作
6. 頁面載入時會先呼叫 `/api/scene/provider-status`，顯示目前是 OpenRouter 還是本地 fallback。
7. 使用者端不顯示 JSON。
8. 改版前的 `/scene` 版面已另存為 `version_snapshots/scene_version_A_20260706/`，可隨時回退。
