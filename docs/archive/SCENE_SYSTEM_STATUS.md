# Scene 生成系統狀態

最後更新：2026-07-07

## 目前定位

`/scene` 是目前專案最接近正式流程的頁面，目標不是讓使用者看到 JSON，而是：

`輸入平面圖 / 條件 -> 後端整理規則 -> 從既有 GLB 家具資料庫挑選 -> 生成可瀏覽的 3D 室內場景`

## 目前使用者流程

1. 上傳平面圖檔，或直接手填房間寬深。
2. 選擇空間類型與固定風格。
3. 勾選希望出現的家具類型。
4. 選擇偏好色系、牆面風格、地板材質。
5. 補充個人需求與限制條件。
6. 送出後直接生成 3D 場景。

## LLM / 後端規劃邏輯

1. `/api/scene/generate` 是目前主入口。
2. 若有設定 `OPENROUTER_API_KEY` 與模型，優先交給 OpenRouter。
3. 若未設定或呼叫失敗，會退回本地 fallback 規則。
4. 即使走 LLM，前端固定指定的風格仍會被保留，不允許任意跳到其他風格。
5. JSON 仍存在後端流程內，但不直接顯示給使用者。
6. 當時另有 AI Agent JSON Schema v1 草案；該草案已於 2026-07-21 移出現行 repo 封存，不是目前 `/scene` 契約。

## 家具挑選與配置

1. 家具來源是 `sf3d/metadata/ikea_furniture_style_database.json`。
2. 目前會依固定風格、家具類型、可用 GLB、尺寸欄位去挑選候選家具。
3. 已正式接入 `furniture_engine/`：
   - 後端會先做房間、牆體、碰撞與邊界檢查
   - 不再只靠前端簡化 box reflow
4. 目前支援的場景操作：
   - `replace`
   - `remove`
   - `add`
   - `reshuffle`
5. 以上動作都會重新走後端配置，而不是單純前端假移動。

## DXF 匯入現況

1. DXF 解析邏輯已從歷史 RoomPilot 參考流程移植到 `web_fastapi/dxf_floorplan.py`。
2. 匯入 DXF 後，後端可解析：
   - `wall_segments`
   - `door_segments`
   - `window_segments`
   - `plan_segments`
3. 前端 viewer 在 DXF 模式下，會優先以 DXF 線段建立 3D 牆體。
4. 目前已修正：
   - 匯入 DXF 後被誤切回矩形房間模式
   - 只顯示地面線、不顯示立體牆
   - 視角旋轉時牆體過度淡出
5. 目前尚未完全解決：
   - 不規則房間 polygon 等級的精準避障
   - 依內牆精準吸附家具
   - 各種 CAD 圖層格式差異的通用化判讀

## 目前前端操作規則

1. `/scene` 已改成單欄流程：
   - 上半部條件設定
   - 下半部 3D 結果
2. 目前表單已進一步改成下拉式選項為主：
   - 空間類型
   - 固定風格
   - 家具組合
   - 偏好色系
   - 牆面風格
   - 地板材質
   - 空間策略
3. 取消原本 1/2 固定高度與雙內部滾輪，改成整頁自然往下操作。
4. viewer 目前保留：
   - 俯視
   - 入口視角
   - 角落視角
   - 室內視角
   - 重設視角
5. 舊的單件旋轉操作已弱化，避免使用者在操作上不順手。
6. 改版前版本已備份在 `version_snapshots/scene_version_A_20260706/`。

## 牆面 / 地板視覺

1. 牆面與地板選項目前已進入 `/scene` 正式流程。
2. 3D viewer 會依選擇套用對應材質方向：
   - 木地板
   - 磁磚
   - 大理石
   - 微水泥
   - 礦物塗料 / 暖白牆 / 灰牆
3. 目前版本使用程式生成紋理，目標是先提供「辨識得到」的材質感。
4. 若要提升質感，下一步應優先導入更高品質的無縫貼圖，而不是只加更多顏色選項。

## 已完成的重要修正

1. 同風格替換不再抽回同一件家具。
2. 家具清單已有編號，可對應 3D 場景中的標記。
3. 替換邏輯會優先找相同風格、相同類型的其他候選家具。
4. 牆面會在擋住視角時自動淡出，離開後恢復。
5. DXF 模式不再強制退回單一矩形房間。

## 目前仍要注意的限制

1. DXF 雖已能正確建牆，但並不是所有 CAD 檔都能直接無誤解析。
2. 家具搭配仍以規則與候選池為主，不等於真正設計師等級的整體美感判斷。
3. 牆地紋理已比純色好，但仍屬前端示意等級，還不是最終擬真版本。
4. 若使用 OpenRouter，品質會受模型、提示詞與回傳穩定度影響。
