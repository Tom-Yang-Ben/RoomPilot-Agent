# 六風格提案語彙

> 搭配 `SKILL.md` 步驟 3 使用。這裡是**寫故事的語彙**，與 `roompilot-furniture-query`
> 的檢索詞彙不同——那份是給機器比對的受控詞，這份是給屋主讀的。
> 但**風格名與色票名必須一致**，否則屋主拿提案裡的詞回來找家具會找不到。
>
> 色票來源：`backend/catalog/data/taiwan_style_cards.json`（v2.0）。

---

## 用法

`prose.json` 的 `style_card` 決定提案頁首的色帶。挑選原則：**看 payload 的
`rooms[].style`，再從該風格的三張色票裡挑最貼近生圖調性的那張。**
不要挑跨風格的色票——色帶與文案講的風格對不上，屋主一眼就看得出來。

## scandinavian 北歐風

| 色票 | 色階 | 適合的敘事 |
| :--- | :--- | :--- |
| 自然木質 | `#F3EBDD` `#D3B48A` `#8B684B` | 木紋、觸感、日光落在材質上 |
| 清新明亮 | `#F7F5ED` `#DCE7DF` `#A5C0B0` | 通透、綠意、早晨感 |
| 低彩度質感 | `#E8E6DF` `#B9B5A9` `#6E706D` | 內斂、灰階層次、成熟 |

**可以講**：夠用就好的克制、材質誠實、留白讓光有地方落下、線條圓潤不鋒利。
**不要講**：性冷淡、極簡到空無一物（那是 modern_minimal 的地盤）。

| :--- | :--- | :--- |
| 侘寂自然 | `#D8D0C1` `#A89B87` `#625B50` | 不完美之美、時間的痕跡 |

## 寫作紅線

這幾類句子一定要避開，它們不是文筆問題，是**會讓提案失去可信度或惹上麻煩**：

| 禁用 | 為什麼 |
| :--- | :--- |
| 任何數字（面積、金額、坪數、尺寸、天數、百分比） | 腳本會排版好；你寫的會被 `verify_numbers.py` 擋下 |
| 「比市場行情省下 N%」「業界最低價」 | 沒有資料支撐，且是不實廣告風險 |
| 「已完成結構／法規評估」 | `risks` 明確列為待專業確認，反著寫是重大誤導 |
| 「保證」「絕對」「零風險」 | 提案不是承攬契約 |
| 「我們為您挑選的家電」 | 家電不在家具型錄，屬 MEP 建議 |
| 自創風格名（侘寂輕奢、日系工業） | 屋主拿這個詞回來檢索會找不到家具 |

## 語氣

寫給要花幾百萬、而且會住十年的人看。他們不需要被哄，需要**看懂你為什麼這樣決定**。

- 講理由，不要只講形容詞。「地坪不做切割」比「大器開闊」有說服力。
- 承認取捨。「我們選擇不去破壞原有比例」比「全面升級」誠實。
- 讓數字自己說話——它們就在旁邊的表格裡，文案不必重複。
