# 口語 → 受控詞彙對映

> 搭配 `vocabulary.md`（詞表本體）使用。本檔是**轉譯規則與踩過的坑**。
> 對映有疑義時，以 `backend/spatial_data/rag/data/` 的檔案為準。

## 1. 風格口語對映

| 屋主可能說 | 對映 | 備註 |
| :--- | :--- | :--- |
| 北歐、北歐風、nordic、scandi | `scandinavian` | |
| 日式、和風、無印風、侘寂、japandi | `japanese` | japandi 是日式北歐混血，取 japanese（與 scandinavian 相容度 0.9，撈得到兩邊） |
| 極簡、簡約、性冷淡風、現代感、minimalist、modern、contemporary | `modern_minimal` | 全庫 44%，最保險的落點 |
| 奶油風、奶茶色、奶油系、柔霧感 | `cream` | |
| 工業風、loft、水泥感、鐵件感 | `industrial` | |
| 美式、鄉村風、中古世紀、mid-century、輕奢 | `american` | |

### 沒有對應的舊詞（必須換掉，並告訴使用者）

舊分類有 12 種風格，其中 6 種在現行六風格**找不到對應，佔舊庫 33.6%**。
遇到這些詞不要沉默地硬塞，換完要講：

| 舊詞 | 建議落點 | 理由 |
| :--- | :--- | :--- |
| 波希米亞 / boho | `scandinavian` | 天然纖維、編織質感最接近 |
| 法式鄉村 / french_country | `cream` | 法式柔霧色卡最接近；純映射只能撈到 127 筆，實際奶油風有 560 筆 |
| 鄉村 / rustic | `american`（鄉村溫馨色卡） | 若強調原木素樸可考慮 `japanese` 的質樸調 |
| 中古世紀 / mid_century | `american` | 舊庫最大宗（1,387 筆），現多落在 american 與 modern_minimal |
| 當代 / contemporary | `modern_minimal` | |
| 輕奢 / scandi_luxe | `american`（現代輕奢色卡）或 `cream` | 看屋主偏冷（american）或偏暖（cream） |

**話術**：「『波希米亞』在系統的六種風格裡沒有對應，我用最接近的北歐風＋自然木質色卡去找，
編織與天然纖維的質感會保留。如果找出來的東西太素，我們再往奶油風調。」

## 2. 氛圍口語對映（★ 最容易失分的地方）

`mood_score` 是**逐字集合交集**，寫錯就是 0 分。下表左邊是常見說法、右邊是詞表裡真正存在的詞：

| 屋主說 | 詞表要寫 | 說明 |
| :--- | :--- | :--- |
| 溫暖、暖暖的、有溫度 | `溫馨` 或 `溫潤` | 布藝軟裝取溫馨，木質觸感取溫潤 |
| 安靜、平靜、放空 | `寧靜` 或 `靜謐` | 兩個都在詞表，可並用 |
| 簡潔、乾淨、清爽 | `俐落` 或 `純粹` | |
| 舒服、舒適、好放鬆 | `放鬆` | |
| 大氣、氣派 | `大器` | ★ 是「器」不是「氣」 |
| 典雅、有質感 | `優雅` 或 `精緻` | |
| 樸素、素樸、原始 | `質樸` | |
| 奢華、高檔、貴氣 | `高級` | |
| 隨性、不拘小節、街頭感 | `率性` | |
| 童趣、可愛、有活力 | `活潑` | |
| 冷靜、穩重、內斂 | `沉穩` | |
| 城市感、都市感 | `都會` | |
| 懷舊、有年代感 | `復古` 或 `懷舊` | 兩個都在 |
| 療癒、放鬆身心 | `療癒` | |
| 明亮、採光好 | `明亮` | |
| 多彩、有顏色 | `繽紛` | |
| 粗獷、原始感 | `粗獷` | |
| 自然、有生命力 | `自然` | |
| 浪漫、少女感 | `浪漫` | |

**不在詞表、找不到落點的詞**（如「未來感」「工業風的冷」「有個性」）→
寧可**不寫氛圍**（回中性 0.5），把那個感覺寫進語意描述裡讓向量去抓，
不要硬塞一個不像的詞（0 分，還吃掉三個名額之一）。

## 3. 量體與尺寸：分辨「感受」和「數字」

這是本系統踩過**最貴**的坑。解析器初版會憑常識填「沙發應該 220 公分寬」，
而尺寸是硬過濾——猜錯直接把正確結果砍光，而且從結果上看不出來。

| 屋主說 | 這是什麼 | 怎麼寫 |
| :--- | :--- | :--- |
| 「沙發不要太大」 | 感受 | 寫進語意：「小尺度、低矮貼地量體」。**不寫公分** |
| 「客廳很小」 | 感受 | 寫進語意：「輕量體、視覺輕盈」。**不寫公分** |
| 「牆面只有 180 公分」 | 數字 | 硬過濾 `max_width_cm`，寫進檢索句 |
| 「樑下高度 210」 | 數字 | 硬過濾 `max_height_cm` |
| 「放得下三個人」 | 感受 | 寫進語意：「三人座」。三人座不等於固定公分 |

判準一句話：**屋主嘴裡有沒有出現數字。** 沒有就不要生一個出來。

`lint_query.py` 會在檢索句出現數字＋長度單位時 FAIL，確實是屋主給的就加 `--sized-by-client`。

## 4. 價格

| 屋主說 | 怎麼寫 | 對應欄位 |
| :--- | :--- | :--- |
| 「兩萬以內」「不超過 15000」 | 「預算 2 萬以內」 | `price_max` |
| 「一整組十萬」 | 「一整組，總預算 10 萬」 | `budget_total`（依中位價比例分配 ×1.3） |
| 「便宜一點」「不要太貴」 | 「平價」 | `price_level=budget`（≤p33） |
| 「中等就好」 | 「中等價位」 | `price_level=mid` |
| 「想買好一點的」「不在意價格」 | 「高階」 | `price_level=premium`（≥p67） |

**互斥**：具體金額與相對詞不要同時出現。「預算兩萬，想找便宜的」→ 只寫「預算 2 萬以內」。

## 5. 完整轉譯範例

### 例 1：單品項，只有調性

```
屋主：「想弄成日本那種很空、有木頭的客廳，沙發不要太大」

拆解  空間=客廳 ｜ 調性=日式、留白、木質 ｜ 品項=沙發 ｜ 約束=無 ｜ 感受=不要太大

query = "客廳，japanese 日式、侘寂自然色卡，寧靜／自然／溫潤；要一張沙發；
淺色實木框架搭配米白亞麻布，低矮貼地量體、線條乾淨、素色，留白感強"
```

沒有公分數（「不要太大」是感受）、沒有價格（屋主沒提）。

### 例 2：只有風格，沒有品項

```
屋主：「臥室想弄成 loft 那種調調，牆面深色水泥」

query = "臥室，industrial 工業風、黑鐵水泥色卡，率性／粗獷／沉穩；
深灰水泥質感與黑鐵件，深色木紋，結構外露、量體厚重"
```

**刻意不寫品項**——屋主沒說要什麼，讓它跨類別檢索（`category_group=null`），
同時追問：「想先看床架、床頭櫃，還是燈具？」

### 例 3：成套配置 + 總預算

```
屋主：「北歐風溫馨感的客廳，幫我配一整組，預算十萬」

query = "客廳，scandinavian 北歐風、自然木質色卡，溫馨／明亮／放鬆；
要一整組客廳配置：沙發、茶几、地毯、落地燈、單椅；
淺色橡木與米白布藝，圓潤簡潔線條，淺色調、素色為主；一整組總預算 10 萬"
```

預算會依各群組中位價比例分配（沙發約 48%、單椅 23%、茶几 12%、地毯 12%、燈 5%），
不是每件 2 萬。回傳後檢查 `is_inferred` 的品項合不合房型（已知會夾帶不合適品項）。

### 例 4：有真實尺寸限制

```
屋主：「餐廳想放一張餐桌，牆到牆只有 180 公分，現代簡約風」

query = "餐廳，modern_minimal 現代簡約、黑白俐落色卡，俐落／純粹；
要一張餐桌，寬度上限 180 公分；霧面烤漆或淺色木質桌面、細金屬腳、幾何直線造型"

送出：lint_query.py "…" --sized-by-client
```

180 是屋主給的，可以進硬過濾。

### 例 5：資訊不足——先給結果再追問

```
屋主：「想找便宜一點的椅子」

query = "平價椅子；簡潔基本款、素色、淺色木質或塑料材質"

同時追問：「是餐椅、辦公椅，還是客廳的扶手椅？三種在系統裡是不同群組，
我先撈了平價的單椅給你看。」
```

不要因為要追問就給空畫面。先撈、再問、把答案併回原句重跑。

## 6. 診斷速查

| 症狀 | 最可能的原因 | 先試這個 |
| :--- | :--- | :--- |
| 回 0 筆 | 尺寸硬過濾 | 拿掉尺寸再跑一次 |
| 回 0 筆，且風格是日式／工業 | 小樣本（181／450 筆）疊上房型與價格 | 先拿掉價格，再拿掉房型 |
| `style` 分數普遍 0.2–0.5 | 要求了相斥風格，或物件只有 `style_secondary` 命中 | 只留一個風格，補色卡名 |
| `mood` 全是 0 | 氛圍詞不在 24 詞表內 | 查上面對映表換詞 |
| `rerank` 普遍 <0.3 | 語意描述太短太抽象 | 補材質、顏色、造型、量體，寫到 30–120 字 |
| 品項全跑掉 | 群組沒寫或寫了不存在的類別 | 對照 19 群組表挑一個 |
| 撈到浴室／戶外的東西 | 沒寫房型 | 補房型 |
| 撈到家電、窗簾 | 那些不在型錄 | 移到問卷／`render_context` |
